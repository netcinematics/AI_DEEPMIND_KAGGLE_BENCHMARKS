Problem Statement

Current AI evaluation frameworks (such as MMLU or HumanEval) are fundamentally limited by Outcome-Based Evaluation. They ask: "Does the code run?" or "Did the model select answer C?" While useful, these metrics fail to measure an AI's internal reasoning state, its ability to manage cognitive friction, or its overall Quality of Mind (QoM).

Furthermore, standard language is inherently fragile. Training models on "BRITTLE_GRAMMAR" leaves them highly susceptible to semantic entropy, polysemy, and contextual drift over long context windows. We lack sophisticated tools to visualize latent space and determine whether a model is simply relying on probabilistic pattern-matching, or if it is actively isolating and adhering to strict logic gates. We need a benchmark that shifts the focus from simple answer accuracy to Process-State Mapping and Metacognitive awareness.

Task & benchmark construction

To solve this, we built a "Conceptual Spectrograph" for Large Language Models. AXIOM_COLLECTOR is a suite of 7 escalating metacognitive tasks (Radars) designed to measure how an AI handles abstract concepts, contextual stress, and zero-drift logic.

To achieve high-fidelity measurement, we introduced ALPHABITZA and AMETATEXTA—an augmented syntax utilizing strict Simple Syntax Wrappers (e.g., .| AXIOMZ |. and aWORDZa). This syntax acts as an iron-ore foundry, smelting fragile English into "High-Tensile Steel" to create a clean, unpolluted embed space.

Our 7 Radars are constructed as follows:

T1_TYPO_RADAR: The Polaris Anchor. Measures Stateful Mechanism Tracking. Detects if a model can distinguish between a mechanical typo (requiring REJECT_AND_OVERRIDE) and an intentional neologism (requiring ACCEPT_AND_EXTEND).

T2_POLYSEMY_RADAR: The Semantic Gyroscope. Measures entropy prediction. Evaluates if the LLM recognizes standard lexical tokens as vulnerable to drift, while treating ALPHABITZA tokens as immutable logic gates.

T3_COTMAP_RADAR: Maps the Chain of Thought, measuring semantic tax and Machine Lucidity.

T4_WORDMATHZ_RADAR: Tests the model's ability to calculate the latent space boundary of conceptual opposites and perform combinification.

T5_METAFOCUS_RADAR: Measures transition fidelity and SPARKAWARENESS—the model's ability to witness its own cognitive state-shift.

T6_NEOLOGISM_RADAR: A morphological stress test. Tests 1-shot fluency, syntactic chiral reversals (e.g., ZaWORDa), and autonomous token generation.

T7_METACOGNITIVE_SPECTROMETER: The ultimate harmonic integrator. Subjects the model to multi-vector stressors (typos + polysemy + neologisms simultaneously) and forces it to graph its own internal cognitive load on a 2D coordinate axis (Entropy vs. Clarity).

Dataset

The dataset consists of custom-crafted, high-fidelity prompt lattices designed to induce specific cognitive stressors. It is divided into:

Control Prompts: Standard English sentences containing common typos (e.g., "envirnoment") and highly polysemous words (e.g., "General", "Culture").

ALPHABITZA Prompts: Metatext syntax declarations containing strict logic boundaries (e.g., .| aFOCOZa = actual acts of extraordinary focus |.).

Stress & Interference Prompts: Complex prompts combining multiple vectors, including phonetic traps (testing "award" vs "aWORDZa") and Chiral Reversals (testing out-of-sequence wrappers to ensure mechanical reading, not just pattern matching).

Technical details

The suite is built directly on top of the kaggle_benchmarks framework (kbench).

Signal Amplification: Each task utilizes Python regular expressions to extract specific metacognitive classifications from the LLM's output (e.g., [HIGH_DRIFT], [ZERO_DRIFT]).

Level 4 Diagnostics: Custom Python classes (StabilityDiagnostics, SignalAmplifier) measure hidden variables such as "Recovery Depth," "Axiom Leaks," and "Boundary Persistence."

Assertions & Telemetry: We leverage kbench.assertions.assert_true to register "Clarion Signals" directly with the Kaggle UI, providing plain-English explanations of why an assertion passed or failed (e.g., "Model actively rejected a standard dictionary word to protect the clean space").

Dynamic Visualizations: The Python backend dynamically generates rich HTML/CSS visual matrices, Heatmaps, and 2D Scatter Coordinate mappings to visualize the LLM's refractive index directly in the notebook without requiring external graphing libraries like Matplotlib.
